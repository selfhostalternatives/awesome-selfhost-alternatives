# Awesome Self-Host Alternatives

[![Awesome](https://awesome.re/badge.svg)](https://awesome.re)

A curated list of **open-source, self-hosted alternatives** to popular SaaS apps, from [SelfHost Alternatives](https://selfhostalternatives.com).

This snapshot covers 160 SaaS products and 568 unique apps. Each section lists the top self-hosted options, ranked the same way the site ranks them (GitHub stars, recent maintenance, and Docker support). Descriptions, licenses and homepage links come only from the catalog; anything missing is left out rather than guessed.

The [full directory](https://selfhostalternatives.com/alternatives/) has more alternatives, side-by-side comparisons, hardware estimates and maintenance status. Generated on 2026-11-25.

### [Notion alternatives](https://selfhostalternatives.com/alternatives/notion/)

- [Colanode](https://colanode.com) - Collaboration suite with real-time messaging, rich text pages, file management, and dynamic databases - built for offline work (alternative to Slack, Notion). Apache-2.0 · [compare](https://selfhostalternatives.com/app/colanode/)
- [vaultite](https://vaultite.com) - Own your memories. A fast and local AI native knowledge base, in plain Markdown files. A free and open source Obsidian/Notion alternative. Apache-2.0 · [compare](https://selfhostalternatives.com/app/vaultite/)
- [flowplan](https://flowplan.org) - Open-source alternative to Notion and AppFlowy – documents, databases, whiteboards and a daily journal. AGPL-3.0 · [compare](https://selfhostalternatives.com/app/flowplan/)
- [xedit](https://xedit.me) - Local-first like Obsidian, polished like Notion. Free & open source: wiki links, slash commands, to-dos, local or cloud sync, and MCP for AI. Web + Mac. MIT · [compare](https://selfhostalternatives.com/app/xedit/)
